# Quetra Engine

A lightweight 2D game engine and visual editor written in JavaScript.

Quetra provides a simple visual editor, runtime, scripting system and project serialization for creating 2D games directly in the browser.

## Features

- 🎮 2D Scene Editor
- 🖱️ Drag & Drop Objects
- 📜 JavaScript Object Scripts
- 🌐 HTML Overlay UI
- 🎨 Texture Support
- 📦 Multiple Export Formats
  - JSON
  - NOJSON
  - Binary
  - Lambda Dump (Experimental)
- ⚡ Real-time Preview
- 🧱 Basic Collision System
- 📝 Embedded Debug Console

## Roadmap

- Audio System
- Animation System
- Tilemaps
- Particle System
- Camera
- Physics Improvements
- Mobile Export
- Plugin API


## Experimental

Quetra includes an experimental Lambda Calculus exporter,
which serializes project data using Church numerals.

This format exists for research and experimentation and is
not intended for production use.
